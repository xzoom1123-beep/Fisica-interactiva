FÍSICA INTERACTIVA: MOVIMIENTO Y FUERZAS
RED para grado 9°.

Archivos:
- index.html
- css/style.css
- js/script.js

Uso:
1. Abre index.html en Chrome, Edge o Firefox.
2. Escribe nombre y curso.
3. Recorre los módulos, simuladores, laboratorio, Escape Room y evaluación.
4. El progreso se guarda localmente con localStorage.

Nota SCORM:
Esta versión es un RED web funcional. No se declara como paquete SCORM. Para uso en Moodle/Chamilo como SCORM, debe realizarse el empaquetado técnico y pruebas de compatibilidad correspondientes.
